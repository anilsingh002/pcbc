# Prayagraj Charitable Blood Centre (PCBC)
### Modern, Responsive & Mobile-Friendly Web Portal

A state-of-the-art web application developed for **Prayagraj Charitable Blood Centre** (Tagore Town, Prayagraj, UP – 211002).

---

## 🌟 Key Features

1. **24/7 Top Emergency Bar**
   - Direct helpline links: `0532-3552983` & Emergency Cell `+91 94152 18900`.
   - Real-time emergency blood dispatch status indicator with animated pulse badge.
   - eRaktkosh registered partner credential display.

2. **Hero Section & Quick Stock Finder Console**
   - High-impact visuals with custom-generated clinical imagery.
   - Live metrics: 48,500+ units dispatched, 24/7 round-the-clock desk, 100% NAT/CLIA tested, 0% commercial markup.
   - Interactive Quick Finder console allowing users to check live availability of specific blood groups (A+, A-, B+, B-, O+, O-, AB+, AB-) across components (PRBC, SDP Platelets, FFP, Whole Blood) directly from the hero area.

3. **Live Blood & Component Inventory Viewer**
   - Simulated real-time inventory synchronization with last-updated timestamp.
   - Filter by Blood Group and Component.
   - Status indicators: Adequate (>6 units), Moderate (3-6 units), Critical Shortage (≤2 units).
   - One-click "Requisition" and "Donate" actions for every blood group card.

4. **Interactive Blood Compatibility Matrix ("Who Can You Save?")**
   - Toggle between **Red Blood Cells (PRBC)** and **Fresh Frozen Plasma (FFP)**.
   - Interactive blood group selector pills.
   - Dynamic highlighting of who the selected group can safely **DONATE to** and **RECEIVE from**.
   - Clinical factoids explaining universal donors/recipients.

5. **60-Second Donor Eligibility Self-Assessment**
   - 5-question interactive questionnaire aligned with National Blood Transfusion Council (NBTC) and NACO standards (Age, Weight, Donation Interval, Procedures, Health).
   - Real-time scoring with instant pass celebration or compassionate deferral advice.

6. **Specialized Component Banking & 5-Tier Safety**
   - Dedicated service cards for Packed Red Blood Cells (PRBC), Single Donor Platelets (SDP / Apheresis), and Fresh Frozen Plasma / Cryoprecipitate.
   - Spotlight on 5-Tier Safety: 4th Generation NAT/CLIA testing, Gel Card Crossmatching, Rh Phenotyping, and Helmer continuous 24/7 cold chain storage.

7. **Charitable Vow & Free Pediatric Thalassemia Program**
   - Highlighting PCBC's non-profit charitable mission: 100% free blood components for children fighting Thalassemia Major and Hemophilia.
   - Subsidized processing for BPL & Ayushman Bharat beneficiaries.

8. **Virtual Life-Saver Pledge Card Generator**
   - Interactive mini-app: enter donor name, blood group, and locality to generate an instant, stylized virtual donor credential card.

9. **Voluntary Blood Donation Camp Schedule**
   - Upcoming blood drive schedule across Prayagraj (Tagore Town, University of Allahabad, Civil Lines).
   - Interactive "Organize a Camp" request modal for colleges, corporate offices, and residential societies.

10. **Interactive Modals with Toast Notifications**
    - **Emergency Blood Requisition Form**: Hospital name, patient details, blood group, urgency level.
    - **Donor Appointment Booking Form**: Preferred date, time slot, donation type.
    - **Camp Request Form**: Organization name, coordinator, expected donors.
    - Simulated order/appointment ID generation and feedback toasts.

11. **Mobile-First & Ultra-Responsive Navigation**
    - Glassmorphic sticky header.
    - Full mobile slide-out navigation drawer.
    - Floating one-tap emergency call button on mobile screens.

## 🚀 How to Run Locally

### Option 1: Direct File Open
Simply double-click `index.html` in File Explorer or open it in any modern browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Python)
Run the following in PowerShell/terminal:
```powershell
python -m http.server 5173
```
Then open [http://localhost:5173](http://localhost:5173) in your browser.
